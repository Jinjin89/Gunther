# 展开方式

一份报告选一种展开方式。用户指定了风格时，风格对应的方式已经定了；结构为“自动”时，按核心问题的类型选。下面每一节的标题是这种方式的编号。

| 核心问题的类型 | 编号 | 对应的风格 |
| --- | --- | --- |
| 是什么、现状如何 | what | 概览 |
| 为什么 | why | |
| 怎么做（步骤） | how | |
| 怎么用好一样东西 | guide | 实用指南 |
| 选哪个 | which | 决策简报 |
| 怎么变化的 | change | |
| 需要先学会才能理解 | learn | 教学路径 |

除了 learn，都**结论先行**：第一章的标题就是核心回答。

## what

**适合**：介绍一个主题、领域或现状，读者需要一个全景。

**安排**：
1. 核心回答：用一句话概括现状，列出它的几个组成部分。
2. 把主题拆成互不重叠、合起来没有遗漏的几部分，最重要的在前。每章讲一部分，说明它在全局里的位置。
3. 结尾：这几部分合起来说明了什么，哪些还不清楚。

## why

**适合**：解释一个现象、结果或问题的原因。

**安排**：
1. 核心回答：主要原因是什么。
2. 先确认现象本身（有多严重、证据是什么），再按重要性逐个讲原因：主要原因在前，每个原因有证据和案例。说明原因之间的关系（叠加、因果链、各自独立）。
3. 排除掉的解释：材料里提到但证据不支持的原因，简短说明为什么排除。
4. 结尾：知道原因以后意味着什么，能做什么。

## how

**适合**：说明怎样完成一件事，读者要照着做。

**安排**：
1. 核心回答：整个过程的要点，以及最关键的一步。
2. 按步骤顺序，每章一步或一个阶段：做什么、为什么这样做、证据或案例、常见错误。
3. 结尾：完成后怎样判断做对了，下一步是什么。

## guide

**适合**：介绍一种方法、工具或做法，让读者知道何时用、怎么用好。

**安排**：
1. 核心回答：它是什么，最适合解决什么问题。
2. 什么时候用、什么时候不该用。
3. 怎么用：关键步骤或要点，配具体案例。
4. 常见陷阱和应对办法。
5. 结尾：开始使用时最该记住的几点。

## which

**适合**：在几个选项之间做选择，读者要做决定。

**安排**：
1. 核心回答：推荐哪个，一句理由。
2. 选项是什么，用什么维度比较（成本、效果、风险、所需条件……），为什么是这些维度。
3. 逐个维度比较各选项，每个判断有证据。用表格汇总时，表格之外仍要写出结论。
4. 推荐和它的条件：在什么情况下推荐会改变。
5. 风险和应对。

## change

**适合**：讲清楚一件事怎样随时间变化、为什么变化。

**安排**：
1. 核心回答：总的变化趋势和最关键的转折点。
2. 按阶段分章，每章说明这个阶段的特征、变化的原因和证据。
3. 结尾：现在处在哪个阶段，接下来可能怎样变化（推断要写明是推断）。

## learn

**适合**：读者需要先掌握一些基础，才能理解结论；常见于写给学生。

**安排**：
1. 第一章：核心问题，以及为什么值得学。
2. 从读者已经知道的讲到不知道的，每章只引入一两个新概念，概念第一次出现时解释，配一个例子。
3. 每章结尾留一个读者可以自测的问题。
4. 最后一章才给出核心回答，并把前面的概念串起来。
