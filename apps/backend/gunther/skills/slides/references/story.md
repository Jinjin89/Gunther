# 故事结构

一份 PPT 的基本骨架：

**开场**（背景 → 冲突或问题）→ **核心信息** → **支撑部分**（每个论点 1–3 页）→ **要点与行动**

开场要短：一两页讲清楚“为什么现在要谈这件事”，然后尽早给出核心信息。支撑部分按核心问题的类型安排，下面每一节的标题是这种结构的编号。

| 核心问题的类型 | 编号 |
| --- | --- |
| 是什么、现状如何 | what |
| 为什么 | why |
| 怎么做（步骤） | how |
| 怎么用好一样东西 | guide |
| 选哪个 | which |
| 怎么变化的 | change |
| 需要先学会才能理解 | learn |

除了 learn，核心信息都在前几页出现。

## what

全景（一页说清有哪几部分）→ 每部分一到两页，最重要的在前 → 趋势或尚不清楚的地方 → 要点。

常用版式：卡片（几个组成部分）、大数字（一个关键规模）、比较表。

## why

现象（有多严重，用大数字或图表）→ 主要原因 → 次要原因 → 排除掉的解释（可选）→ 这意味着什么 → 要点。

常用版式：大数字、流程（因果链）、柱状图（各原因的影响大小）。

## how

目标 → 步骤（总览一页，用流程；关键步骤各一页）→ 风险和应对 → 要点（第一步做什么）。

常用版式：流程、两栏（做法对比：常见做法 / 推荐做法）、卡片。

## guide

它是什么、解决什么问题 → 什么时候用、什么时候不用（两栏）→ 怎么用（流程或卡片）→ 常见陷阱 → 要点。

## which

选项 → 比较维度 → 逐项比较（比较表，或每个关键维度一页）→ 推荐和条件 → 风险 → 要点（决定和下一步）。

常用版式：比较表、两栏、柱状图。

## change

总趋势（折线图或时间线）→ 每个阶段一页：特征和变化的原因 → 现在处在哪里、接下来可能怎样（推断要写明）→ 要点。

常用版式：时间线、折线图、大数字。

## learn

问题和为什么值得学 → 从已知到未知，每页只引入一个新概念，配一个例子 → 把概念串起来 → 最后才给出核心信息 → 要点。

常用版式：文字、引文（定义）、流程（概念之间的关系）。
