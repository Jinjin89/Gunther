# 版式

问自己：**这一页的内容之间是什么关系？** 版式由关系决定。下面每一节的标题是版式的编号。

| 内容关系 | 版式 | 编号 |
| --- | --- | --- |
| 题目和核心信息（只用于第一页） | 标题页 | title |
| 一个数字或一句话最重要 | 大数字 | big_number |
| 几个对象在多个方面比较 | 比较表 | compare |
| 两种观点、前后对比、利弊 | 两栏 | two_column |
| 步骤、流程、因果链 | 流程 | flow |
| 随时间变化 | 时间线 | timeline |
| 几个量比大小、占比 | 柱状图 | bar_chart |
| 一个量随时间的趋势 | 折线图 | line_chart |
| 分类、组成、并列的几个要点 | 卡片 | cards |
| 原话、定义、关键引述 | 引文 | quote |
| 需要解释推理，以上都不是 | 文字 | text |
| 结论和下一步（只用于最后一页） | 要点 | takeaways |

除了标题页，每页都以 `## 标题` 开始，标题就是这一页的结论；最后可以加一行 `Note:`，后面写讲者备注（演讲用必须写）。下面每一节写明正文怎么写。

## title

**适合**：第一页。

**写法**：`# 题目`，下一行是一句核心信息。没有要点、没有出处、没有讲者备注。

```
# 小样本学习在医学影像中的现状
现有方法已能用于筛查，但还不能替代诊断
```

## big_number

**适合**：一个数字（或一句很短的话）最重要，其余都是说明。材料里只有一两个数字时，用它而不是图表。

**写法**：一行加粗的数字或短语，下一行说明它和什么相比、来自哪里，标出处。一页只放一个大数字。

```
## 人工成本占总成本的大头
**62%**
三年总成本中人工的占比，远高于设备的 18% [3]
```

## compare

**适合**：两到四个对象在几个方面比较。

**写法**：一张表，第一列是比较的方面，后面每列一个对象；每格要短，有出处。表下面一句话写出结论。最多 4 个对象、5 个方面。

```
## A 方案的三年总成本比 B 低三分之一
| | A 方案 | B 方案 |
| --- | --- | --- |
| 前期投入 | 120 万 [2] | 80 万 [2] |
| 三年运营 | 90 万 [4] | 230 万 [4] |
| 上线时间 | 6 个月 [2] | 2 个月 [5] |
A 前期贵，但运营便宜，第二年起总成本更低。
```

## two_column

**适合**：两种观点、之前与之后、利与弊，两边用相同的维度对照。

**写法**：一张两列的表，表头是两边的名称，每行是同一个维度在两边的情况，有出处。

```
## 推荐做法把错误率降了一半
| 常见做法 | 推荐做法 |
| --- | --- |
| 人工逐条核对 [1] | 先自动筛查，再人工复核 [1] |
| 错误率 8% [1] | 错误率 4% [1] |
```

## flow

**适合**：有先后的步骤、流程，或一环扣一环的因果链。内容没有先后就不要用。

**写法**：编号列表，每步一个短语，最多 6 步；需要时在短语后标出处。

```
## 数据先清洗再标注，返工最少
1. 去重和格式统一 [2]
2. 自动预标注 [3]
3. 人工复核有争议的样本 [3]
4. 抽样质检 [5]
```

## timeline

**适合**：随时间的变化，要标出转折点。

**写法**：列表，每行以加粗的时间开头，后面一句话，有出处。最多 7 个节点。

```
## 2020 年以后增长主要来自海外
- **2016** 首个产品上市 [1]
- **2020** 进入欧洲市场，海外收入首次超过三成 [4]
- **2023** 海外收入占六成 [6]
```

## bar_chart

**适合**：几个量比大小，或各部分的占比。数据必须全部来自材料。

**写法**：一张表，第一列是名称，第二列是数值（表头写明单位），每行标出处。表下面一句话说明要看什么。不能估算、补全或编造数据；材料里只有一两个数字时，改用大数字。最多 6 行。

```
## 人工是成本里最大的一项
| 项目 | 占比（%） |
| --- | --- |
| 人工 | 62 [3] |
| 设备 | 18 [3] |
| 其他 | 20 [3] |
人工一项就超过其余两项之和。
```

## line_chart

**适合**：一个量随时间的趋势。数据必须全部来自材料。

**写法**：一张表，第一列是时间，第二列是数值（表头写明单位），每行标出处。表下面一句话说明趋势或转折点。最多 6 行。

```
## 2021 年以后增速明显放缓
| 年份 | 用户数（万） |
| --- | --- |
| 2019 | 12 [2] |
| 2020 | 30 [2] |
| 2021 | 41 [5] |
| 2022 | 44 [5] |
2020 年翻了一倍多，之后每年只增长一成左右。
```

## cards

**适合**：并列的几个组成部分、类别或要点，彼此没有先后。

**写法**：3–6 条列表，每条以加粗的名称开头，后面一句话，有出处。

```
## 误差主要来自三个环节
- **采集**：设备之间亮度不一致 [2]
- **标注**：边界病灶的分歧最大 [4]
- **模型**：小样本类别容易过拟合 [5]
```

## quote

**适合**：一句原话、一个定义，原样引用比转述更有力。

**写法**：一段引用，下一行写明是谁说的、出自哪里，有出处。只引一段。

```
## 监管方把“可解释”放在准确率之前
> 无法说明判断依据的模型，不应单独用于诊断。
— 某监管指南，2023 [6]
```

## text

**适合**：需要解释一段推理，以上版式都不合适。它是兜底，不是默认。

**写法**：演讲用不超过 3 条短语；阅读用 2–4 个完整的句子。每条有出处。

```
## 准确率高不等于能直接上线
- 测试集和真实病人的分布不同 [3]
- 罕见病例几乎没有样本 [4]
- 出错的代价远高于漏检 [?]
```

## takeaways

**适合**：最后一页。

**写法**：标题写一句总的结论或行动；下面不超过 3 条要点或下一步，和核心信息一致，有出处。

```
## 先用于筛查，再逐步扩大
- 筛查环节的准确率已经够用 [2]
- 诊断环节还需要更多罕见病例数据 [4]
- 下一步：在一家医院试点六个月
```
