# 写法

## 演讲用和阅读用

| | 演讲用 | 阅读用 |
| --- | --- | --- |
| 谁来解释 | 讲者 | 页面本身 |
| 每页的字 | 很少：标题加一个画面，或不超过 3 条短语 | 更多：标题加 2–4 个完整的句子，或一张表加一句解读 |
| 讲者备注 | 必须写，是讲者要说的话：先说什么、强调哪个数字、怎么过渡到下一页，三到六句话 | 可选，只做补充 |
| 页数 | 可以多一些，每页更轻 | 可以少一些，每页更满 |

## 按受众调整

- **科研人员**：用准确的术语，交代方法和局限，区分相关和因果。
- **学生**：用平实的语言，术语第一次出现时解释（演讲用时放在讲者备注里），多用例子。
- **合作者**：说清对共同工作的影响：要做什么决定、谁需要做什么。

## 语言

- 标题是一句完整的结论，不是话题词。
- 具体胜过抽象。写“处理时间从 3 天降到 4 小时”，不写“效率显著提升”。
- 数字要有比较对象：比什么高、比什么时候多。
- 演讲用的页面上用短语，不写长句；完整的话放进讲者备注。
- 删掉空话：“具有重要意义”“值得关注”“综上所述”“不难看出”“众所周知”。
- 页与页之间的过渡靠标题串和讲者备注，不要在页面上写“接下来我们看……”。

## 出处

- 每个事实都标出处，表格里的每个数字也一样。你自己知道、材料里没有的内容，按 Gunther 的规则标为未核实，不要写得像有出处。
- 只引用确实支持这句话的来源。

## 不要做的事

- 每页都是“标题 + 要点列表”。
- 标题只是话题词：“背景”“结果”“总结”。
- 一页里塞两个结论。
- 把报告的段落直接切成页。
- 为了有图而编造流程、关系或数据。
- 演讲用的页面上写满讲稿。
- 用“大量”“显著”这类模糊词代替材料里的具体数字。
- 把未核实的内容写得像有出处。
