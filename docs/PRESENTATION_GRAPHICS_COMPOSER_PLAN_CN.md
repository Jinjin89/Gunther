# 将图形纳入组合式构图

2026-10-17。承接元素树组合器。用户要求模型根据内容，把流程图、关系图、数据图表与文字、数字安排在同一页。主代理负责规划和验收，Luna 实现。

## 页面能力

在既有 row/column 元素树中加入 `flow`、`diagram`、`bar_chart`、`line_chart` 四种图形视图。模型仍只引用正文块，决定分组、比例、阅读顺序和显示方式；不重传数字、节点或连线文案。表格与列表继续保留为原始内容，可以选择原文表达，也可以在满足条件时选择图形。

内容块类型与显示视图区分：有序列表可以显示为流程，二列表格可以显示为柱状图或折线图，三列关系表可以显示为关系图。可用视图由程序检查后提供给模型，不按业务名称猜测内容关系。

第一版沿用已有图形范围：2–6 步的有序流程；受限的小型 DAG；2–6 行、单数值序列的柱状图和折线图。数值图要求恰好两列，防止额外数据列在绘图时被忽略。不增加饼图、复杂多系列图或自由绘图语言。

## 内容和证据

模型不能把无序列表变成流程，不能从表格排序制造依赖或因果。流程保留原有编号顺序；关系图逐条保留起点、条件/关系、终点与引用。数据图保留行标签、原始值、单位、负号、比较口径和引用，不补值或计算新值。

选择图形后，复用现有的数值与关系检查，并按选中的内容块核查。关系需要验证方向和条件；数值需要验证每个对象、数值和引用对应。页面其他位置出现相同数字，不足以证明该图的数据正确。为控制调用量，单页至多选择三个图形块；内容仍全部保留，其他块可使用原始列表/表格。

核查未完成、没有所需证据或结构不适合绘图时，该块显示完整原始列表/表格，并给出可见提示及保存记录。其他合法元素继续使用组合布局。设计步骤不能提升正文的事实核查状态。

## 保存合同

新增 scene v2，兼容已有 v1 页面。v2 保留 `sourceHash` 和元素树，增加由程序写入的图形许可与严格内容指纹：

```text
version: 2
sourceHash: 忽略引用编号的构图指纹
graphicsHash: 保留引用标记的可见正文指纹
graphics: { blockId: 经核查允许的图形视图 }
root: 元素树
```

模型只返回 root，不能自行授予图形许可。`graphicsHash` 区分可信的保存重编号与手动更改引用：保存时由代码在确定只是引用重编号后重新绑定；手动改文或改引用则使旧图形许可失效。失效时保留原文，直到重新核查/构图。编辑器继续隐藏元数据，主题切换及保存重开保留有效设计。

后端在写作、编辑、修订、审校和组装路径中执行相同规则，不能通过切换叶子视图绕过原有图表检查。Python/TypeScript 使用共享样例校准结构、可用视图与版本行为。

## 按区域绘图

图形作为真正的页面元素绘制，依据所在区域的宽高排布。复用已有解析、尺度和连接算法，避免把整张旧幻灯片缩进小框。文字和引用继续使用同一组件；SVG 只绘制线条、点和形状。

- 流程根据区域宽度选择横向或纵向，保持步骤顺序。
- 关系图在区域内安排层级与正交连线，节点、边标签及箭头使用同一坐标系。
- 柱状图保留零基线与负值方向；折线图保留真实数值比例和可用的数值横轴，不人为夸大趋势。
- 所有图形保留标签、单位、数值及可点击引用；不截断文字。数据可通过可访问的原始值表达完整保留，隐藏等价内容不产生重复焦点项。

区域过窄、过矮或标签无法清楚排布时，优先调整图形方向与排布；仍无法显示时退回该块的完整来源形式并说明原因。预览、缩略图、放映和打印使用同一实现与数据，不仅检验外层画布，也检查元素内部溢出与重叠。

5. 运行相关前后端回归、类型检查、Ruff 和构建，保存实际浏览器画面与有界合成模型验证。

## 实施记录

已由两名 Luna 子代理分别完成后端和前端，主代理负责方案、代码审查、真实模型探针和浏览器验收。Slides Skill 升至 v9。

- 四类图形已作为元素树的叶子接通。模型能在同一页选择图形、文字、列表和数字的组合、占比与阅读顺序；图形按实际区域尺寸绘制。行容器现在显式填满分配高度，避免嵌套区域浪费空间。
- 图表核查逐行绑定标签、数值和引用；关系图核查方向与条件。核查失败只将该块改回完整原文并在生成记录中保存原因。表格若附带同块说明、存在额外数据列或不兼容单位，不会为了绘图丢掉这些内容。
- v2 图形许可与含引用的正文指纹绑定。可信引用重编号必须提供完整映射；缺失引用、手动改引用或改文都不能继承旧许可。v1 编码继续只包含原来的三个字段。
- 流程保留原始编号；柱状图保留零基线、负值方向及单位；折线图保留数值横轴的实际间隔。关系图同时预算节点、条件文字和引用的尺寸，并检测重叠。图形空间不足时保留完整来源内容，恢复正常正文的字号。
- 修复图形初始化时的错误缩放、强调区域中的文字对比度，以及主预览和放映相互更新测量结果引发的白屏。预览、缩略图、放映和打印组件使用同一绘图实现。
