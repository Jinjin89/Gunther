## 2. Target design per job

### Outputs

**One Studio authoring path.** Use one preparation function and one whole-build implementation for a direct rebuild and the conversation's make action. Give reports, generic slides and study decks the same stage boundary and evidence controls. The writing and scientific stages remain format-specific. Populate the existing `Work` once from the resulting draft. Conversation decisions still choose which operation to apply and retain follow-up questions and the proposed brief. They delegate generation to the same authoring functions used from the HTTP compatibility routes.

- `gunther/output_material.py` owns `def prepare_output_material(session: Session, scope: OutputScope, *, library_id: str, seed: Sequence[Evidence], library_supplements: bool, limits: OutputLimits) -> OutputMaterial`. This extracts the existing scope and material slices at `service.py:3443–3908` for both 4162–4174 and 5622–5650. `OutputMaterial` carries notes, pool, reader, scoped tools and pinned inputs.
