# 演示文稿的视觉设计能力

2026-10-17。承接 Theme 和逐页内容设计。用户提供的截图用于说明“画面有设计意识”，不作为要复刻的模板，不要求特定颜色、边框或装饰。

## 目标和判断

目标是在内容组织与绘制之间建立通用的视觉语言：识别主次、并列、顺序、关系和补充说明，选择能够表达这些关系的设计元素。Theme 决定整套演示的外观；视觉语言决定每页的信息怎样被看见。

目前的 design 阶段已有 intent、visual、composition、emphasis、notes；其中 layout 和少量 composition 真正影响空间，其余主要指导正文。现有渲染器虽然识别了表格、并列项、步骤和图关系，但很多元素的视觉分量接近，分组和阅读层级不够清楚。本轮补齐这条路径，不以截图中的业务对象、措辞或配色建立特殊规则。

## 实施计划

1. 在项目的 Slides Skill 中增加视觉设计方法，并接入设计、写作和编辑阶段。先确定内容关系、视觉焦点和阅读路径，再用已有版式、构图、段落、强调与讲者备注表达。没有依据时不制造重点、排名、因果或分类；不为装饰增加内容。
2. 建立共享的视觉角色和主题派生的颜色角色：主体、支持、同级分组、连接、局部强调。布局组件调用角色，而不是各自硬编码颜色。保留无彩色选项；深浅主题都保证可读性。颜色不能是表达含义的唯一方式。
3. 将语义落实到现有绘制能力：两栏让同级对象形成清楚的区域且行间可比；卡片表达并列分组，不暗示排名；流程呈现顺序和局部解释；关系图用已有拓扑和连线组织阅读；引导语、正文与补充说明具有不同层级。避免给所有页面套相同卡片外壳。
4. 保留用户内容、引用、限定条件、主题和构图。设计必须服从完整显示；长内容采用原有适配/回退机制。旧文稿也能使用共享渲染改善，无需修改事实或增加模型调用。

本轮沿用已有语义版式和内容格式，不声称已实现任意自由布局或完整的自动艺术指导器。设计说明通过写作者选择的结构和强调转成视觉；暂不把自由文字解释成任意坐标、颜色或图标。

## 验收标准

- 用多个领域的合成内容检查，不只做一张与参考图相似的演示。
- 同级对象有相同视觉权重，顺序只来自原有列表，图形连接只来自已有关系，补充内容保持原文和引用。
- 对比、分组、顺序与关系页有适合自身内容的表达，同时属于同一套视觉系统。
- 深浅 Theme、无彩色 Accent、长中英文、标准和已有构图均可读；检查实际浏览器里的溢出、引用按钮和打印路径。
- 运行受影响测试、类型检查和构建。视觉结果以渲染检查为准，不用测试通过数量代表美观。

## 研究依据

- [Apple Human Interface Guidelines：Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：空间、对齐和分组可以传达相对重要性与阅读关系。此处借用通用视觉组织原则，不将界面组件当作幻灯片模板。
- [Microsoft Fluent：Color tokens](https://fluent2.microsoft.design/color-tokens)：按用途定义颜色角色可以把含义和具体颜色分开。本项目的角色由所选演示 Theme/Accent 派生，不照搬 Fluent 的界面配色。

## 验证记录

已由主代理规划与复核、Luna 子代理实现。Slides Skill 升至版本 6，设计、写作、编辑和修订均加载视觉设计方法。渲染器共享分组面、支持文字、结构线、连接与局部焦点角色；颜色由所选 Theme/Accent 派生。并列列头和卡片保持同级权重，流程的已有粗体动作名与解释分层并按行对齐，关系图的起点用于定位阅读入口。后置说明保持支持层级，不自动冠以“结论”等标签。

浏览器检查覆盖 26 个样例 × 4 种主题，其中包含全部 14 个既有版式、长中英文、混合流程语法和两张真实模型生成页。没有画布溢出，引用数量一致；最小 fit 为 0.77，出现在六步长流程的 Editorial 主题。24 种 Theme/Accent 组合中，本轮新增的关键文字/背景组合最低对比度为 4.90:1。图中连接点与节点宽度使用相同比例，缩放后误差低于 0.01 屏幕像素。实际点击了图中引用，并检查了打印 DOM 中的版式、主题与引用传递；未另行逐页检查导出 PDF。

现有 Outputs 模型 DeepSeek Flash 的有界验证实际使用 3 次调用：生成六页设计，再写出流程页和并列卡片页，没有重试或跳过。材料全部为合成测试数据，不读取或修改真实资料库。两页均保留引用、限定说明与所需结构，实际渲染 fit 为 1。设计说明曾将四步描述成纵向，与渲染器的横排规则不符，随后在 Skill 中明确方向由步数决定。记录见 [model_probe.json](../artifacts/validation/presentation-visual-language/model_probe.json)。这次验证不等于全面事实核查或美学评测。
